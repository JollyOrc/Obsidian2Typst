## How to add a story

1. Copy `_TEMPLATE.md` to `US-NNN-short-title.md` (zero-pad to three digits).
2. Fill in every section. For any AC involving a structural or numeric outcome,
   include a concrete before/after example with exact values — "the correct
   level" is not an acceptance criterion (see `scars/SCAR-007-…md`).
3. Include at least one AC for a composed or nested usage of the feature, not
   only the top-level happy path (see `scars/SCAR-002-…md`).
4. Add a row to the index table above.
5. Create the corresponding tickets in `docs/tickets/`.
