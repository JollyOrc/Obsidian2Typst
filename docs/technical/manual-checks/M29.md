# M29 — The statblock as Typst for another plugin: icons and fonts in a real compile (US-039)

Part of the [manual checks](../manual-checks.md).

**When:** after #165 to #167 (US-039), and after any change to
`api.statblockTypst`, `api.compileFonts`, the statblock's Typst writer or the
fonts the export hands the compiler.

**Needs:** Obsidian desktop and a PDF viewer. Prepared by the developer
(SCAR-012): the test build installed in the scratch vault (`npm run
install:scratch`; `main.js`, `manifest.json`, `styles.css` byte-identical to
the fresh build; checksums in the hand-over note); the sample vault `Sample/`
with the five icon files `Sample/assets/icons/*.svg`; the preset `Cards M29`
(`Obsidian2Typst/presets/Cards M29.md`: the sample's entries preset plus
`fonts.folder: Layouting/Fonts` and the credit `Icons: generated shapes,
M29`). `Layouting/Fonts` holds eight font files that load (two DejaVu Sans,
four Nimbus Roman, two C059 in `headings/`), one broken file and one zip
(both reported, neither used). The vault's state before the install is backed
up with a checksum list in the developer's record. Part B uses your own vault;
nothing there is prepared or changed by the developer.

**Run in the scratch vault** (`spikes/typst-wasm/scratch-vault`) for part A,
and in your own vault for part B. **Expected version:** `0.15.0`
(first line of the settings tab, also the plugin list). If it differs, stop:
the wrong build is installed. Restart Obsidian once so the new build is
loaded.

**Known limitations (SCAR-024, SCAR-032, SCAR-045):** the developer measured
in Node (2026-11-12) that the answer's data compiles at 54 mm with the pinned
Typst to a PDF whose text holds the band, boxes, attributes, attacks, skills
and tags, for four icons and for 35 boxes. Not measured: the icons as the real
vault files in that compile, the fonts of a preset's folder, and the new
functions in the real Obsidian. That is this check. The card page here is a
bare page (62 x 88 mm, no frame, no art): only the statblock is checked.

## Steps

### A — the scratch vault

1. Open Settings → Obsidian2Typst. The first line reads `Obsidian2Typst
   0.15.0`. Close the settings.
2. In the ribbon menu choose the preset `Entries`. Open the developer
   console (macOS: Cmd+Option+I) and paste:

   ```js
   const p = app.plugins.plugins["obsidian2typst"];
   const api = p.api;
   const data = {vigour: 11, might: 4, wits: 2, speed: 5,
     attacks: ["Kick: 2d6", "**Bite**: 1d6"], skills: ["Quick Step", "Keen Nose"], tags: ["beast"]};
   const a = await api.statblockTypst(data, {heading: "Fen Hare"});
   console.log("ok", a.ok, "files", a.files.map(f => [f.path, f.bytes.length]), "credit", a.credit, "warnings", a.warnings);
   const fonts = await api.compileFonts();
   console.log("fonts", fonts.length);
   const files = Object.fromEntries(a.files.map(f => [f.path, f.bytes]));
   const source = `#set page(width: 62mm, height: 88mm, margin: 4mm)\n${a.prelude}\n#block(width: 54mm, o2t-sb-box(${a.data}))\n`;
   const r = await p.compiler.compile({file: "card.typ", source, files, fonts});
   console.log("compile", r.ok, r.ok ? r.pdf.length : r.error);
   if (r.ok) await app.vault.adapter.writeBinary("M29 card.pdf", r.pdf.buffer.slice(r.pdf.byteOffset, r.pdf.byteOffset + r.pdf.byteLength));
   ```

   The console shows `ok true`; `files` lists four entries
   `o2t-icons/1.svg` to `o2t-icons/4.svg`, each with a size above 0 (the
   sizes in bytes of `fine.svg`, `hurt.svg`, `down.svg`, `gone.svg`: 110, 121, 105, 121); `credit null`;
   `warnings []`; `fonts 6`; `compile true` with a size.
3. Open `M29 card.pdf` (vault root; open it in the PDF viewer, not
   Obsidian's). One page of 62 x 88 mm. At reading size (100 %, SCAR-025):
   the band `◆ Fen Hare ◆`, the box row with 11 boxes under `VIGOUR 11`, the
   track `STATE` with four cells holding four different icon shapes (circle,
   square, triangle, horizontal bar, as the files draw them; none empty), the
   line `Might 4 · Wits 2 · Speed 5`, the attacks `Kick 2d6` and `Bite 1d6`
   (`Bite` in bold), `Skills: Quick Step, Keen Nose`, the tag `Beast`.
4. Choose the preset `Cards M29` in the ribbon menu (no restart) and run the
   same console text again. Now `credit` is `Icons: generated shapes, M29`
   and `fonts` is `14` (six bundled and eight of the folder); the files and
   the card as before.
5. In the console run:

   ```js
   const bad = await api.statblockTypst({tags: ["beast"]}, {heading: "x"});
   console.log(JSON.stringify(bad));
   ```

   It shows `{"ok":false,"reason":"no-statblock","message":"No statblock: no
   stats or attacks."}`.
6. Delete `Sample/assets/icons/hurt.svg` in Obsidian's file explorer (the
   developer keeps a copy), choose `Entries` again, and run the step 2 text.
   `files` lists three entries, `warnings` holds one
   `STATBLOCK_ICON_MISSING` naming `Sample/assets/icons/hurt.svg`, the card
   shows the `Hurt` cell empty. Put `hurt.svg` back (the developer restores
   it from the backup after the run).

### B — your own vault (optional here; your preset with its icons and fonts)

7. Close Obsidian. In your vault's `.obsidian/plugins/obsidian2typst/`, keep
   a copy of `main.js`, `manifest.json` and `styles.css` somewhere outside
   the vault, then copy the three files of the test build into it. Start
   Obsidian; the version is `0.15.0`.
8. Choose the preset you print with and run the step 2 text with a creature
   of your book as `data` (its properties as an object). `ok true`; `files`
   has one entry per icon the cells draw; `fonts` is six plus the number of
   font files in your preset's fonts folder; the card shows your fonts and
   icons. The PDF lands in your vault's root as `M29 card.pdf`; delete it
   after looking. Put your three files back when done.

### Open question (SCAR-015)

9. Looking at the card from step 3 and 4: is anything missing or different
   from the statblock in your book's PDF for the same creature (band, boxes,
   track, attributes, attacks, skills, tags)? Describe it.
