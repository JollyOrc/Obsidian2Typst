# M36 — A note names its preset and its compile target, end to end in Obsidian (US-045)

Part of the [manual checks](../manual-checks.md).

**When:** after #191, #192 and #193, before the release 0.19.0; ticket #194. Run together with the Vault Compiler's
check M25 (its ticket #140, US-7.5): one run, two records. What the tests cannot show is checked here (SCAR-045):
the two menus and their dialogs in Obsidian, the properties they write, the compile through the installed Vault
Compiler, and the export and preview of the compiled note.

**Needs:** Obsidian desktop. Prepared by the developer (SCAR-012, SCAR-018) in the scratch vault
(`spikes/typst-wasm/scratch-vault`, opened with `Open folder as vault`):

- the **test build `0.19.0-m36.1`** of this plugin and the **test build `0.27.0-m25.1`** of the Vault Compiler,
  both installed (checksums equal to the builds) and enabled;
- invented notes in `M36/`: `Lantern Sheets.md` (no properties yet; embeds `Lantern Moth` and `Lantern Keeper`) and
  `Wrong Preset.md` (`typst-preset: Gone Sheets`);
- the Vault Compiler's settings as "the book's": starting file `Sample/Book.md`, output folder `M36/Book Out`,
  output file `book.md`; this plugin's active preset `Cards M29`; no remembered export folder for `A4 digital`;
- an empty export folder outside the vault: `~/Documents/Gits/Obsidian2Typst/spikes/m36/export`;
- the starting state: `spikes/m36/m36-before.txt` (316 files) and a full copy in `spikes/m36/vault-before/`, made
  while the scratch vault was not open.

**Run in the scratch vault**. **Expected version:** `0.19.0` (first line of this plugin's settings tab). If
it differs, stop.

**Decided before the run (SCAR-032):** each step names what is expected; the check passes when every step shows
it. A difference is written down with its step number and nothing is changed during the run; afterwards each one
is a bug (fixed and re-checked before the release) or a point the owner decides. The compiled text was rehearsed in
Node with the Vault Compiler's core (`spikes/m36/rehearsal/lantern-sheets.md`).

## Steps

1. Settings → Community plugins: **Obsidian2Typst 0.19.0-m36.1** and **Obsidian Vault Compiler 0.27.0-m25.1**, both
   on. Close the settings.
2. Right-click `M36/Lantern Sheets.md` → **`Compile target…`**: a dialog with output folder and file name, both
   empty. Type `M36/Out` and `lantern-sheets.md`, press **Enter**. Expected: the notice
   `✅ Compile target of "Lantern Sheets": M36/Out/lantern-sheets.md`; the note's properties now show `compile-folder`
   and `compile-file`; the text below them is unchanged.
3. Right-click the same note → **`O2T: Preset for this note…`**: a list starting with `Active preset (no property)`,
   then the presets. Type `a4`, choose **A4 digital** with Enter. Expected: `✅ Preset for "Lantern Sheets": A4
   digital`; the properties show `typst-preset: A4 digital`. Open the list again: `A4 digital (current)`; press
   Escape — nothing changes.
4. Right-click the note → **`Compile vault from this file`** (the compile dialog): the output fields show `M36/Out` and
   `lantern-sheets.md`, and the grey line says `Output from the note's properties`. Click **Compile**. Expected: the
   note `M36/Out/lantern-sheets.md`, starting with the properties block holding only `typst-preset: A4 digital`,
   then *Lantern Sheets* with both embedded notes. Open the Vault Compiler's settings: the output is still
   `M36/Book Out` / `book.md`.
5. Open `M36/Out/lantern-sheets.md` and open the style panel (preview): the preset list shows **A4 digital**, greyed
   out, with `Set by this note's properties (O2T: Preset for this note…)`; the pages are A4. Then right-click the note
   → **`O2T: Export to PDF`**: the export dialog opens on **A4 digital**; choose the export folder above and Export.
   Expected: an A4 PDF. Then this plugin's settings: the active preset is still **Cards M29**.
6. Open `M36/Wrong Preset.md`, ribbon → **`Export…`**: the dialog opens on `Cards M29` and shows in red `Preset
   "Gone Sheets" (from this note's properties) does not exist`. Cancel. Then **`O2T: Export to PDF`** on the same
   note: the notice says the same sentence (ending with a full stop) and nothing is exported.
7. Anything missing, odd or ugly that this list did not ask about? Report it even if it seems unrelated.

## Record

Date, both builds, passed or the differences by step. The developer then compares the disk with what the steps
wrote (the notes' properties, the compiled note, the PDF, both plugins' `data.json`) and undoes the vault from the
full copy (`shasum -c m36-before.txt`).
