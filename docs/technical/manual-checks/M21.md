# M21 — Statblocks and entry layouts in the PDF (US-030 to US-033, epic #121)

Part of the [manual checks](../manual-checks.md).

*Amended by epic #139 (0.13.0):* the opening beside the statblock (step 5),
the landscape picture's place (step 6), the portrait forms and the quick
reference's header and columns changed; [M25](M25.md) checks them. The
other steps stand.

**When:** after #122 to #136 (epic #121), and after any change to the entry
layout, the statblock or the openers.

**Needs:** Obsidian desktop and a printer that prints A5 at 100 % (or A4
with "actual size"). Prepared by the developer (SCAR-012): the test build
installed in the scratch vault (`npm run install:scratch`; `main.js`,
`manifest.json`, `styles.css` byte-identical to the fresh build; the
checksum is in the hand-over note). The sample vault's new files of #122 are
in `Sample/` (`Menagerie.md`, `presets/Entries.md`, `assets/entry-*.png`,
`assets/icons/*.svg`), and the preset note
`Obsidian2Typst/presets/Entries.md` (a copy of the sample preset: A5,
facing pages, `headingRules: {Menagerie: entries, Relics: entries}`, the
statblock with five icons, quick reference and encounter sheet on). Only
files were added; the list and checksums of the vault are in the developer's
record (2026-11-07). An empty export folder:
`spikes/typst-wasm/m21-export/1`.

**Run in the scratch vault** (`spikes/typst-wasm/scratch-vault`). **Expected
version:** `0.15.0` (first line of the settings tab, also the plugin
list). If it differs, stop: the wrong build is installed. Restart Obsidian
once so the new build is loaded.

**Known limitations:** only `Dune Lark` breaks the sample's `sum` rule (on
purpose), so the report lists one `STAT_SUM_MISMATCH` (the generator was
fixed 2026-11-07; before, 16). After the chapter's
end the quick reference and sheet pages show their own titles in the
running header since 0.13.0 (#143; before: US-019's rule, page 38 showed
`Fen Hare` with this vault's header level 4). Your own book is not part of
this check.

The numbers below were measured from the files as installed through the
plugin's own `exportCurrentNote` and `runExport` with the bundled compiler
(2026-11-07, scratch probe `m21probe.test.ts`).

## Steps

1. Open Settings → Obsidian2Typst. The first line reads `Obsidian2Typst
   0.14.0`. Close the settings.
2. In the ribbon menu choose the preset `Entries`. Open `Sample/Menagerie.md`
   and run `O2T: Export to PDF` into `spikes/typst-wasm/m21-export/1`. The
   notices read `Compiling…` and `Exported with 29 warnings`.
3. The folder holds `Menagerie.pdf`, `Menagerie.typ`,
   `Menagerie - Encounter Sheet.pdf`, `Menagerie - Encounter Sheet.typ`,
   `export-warnings.md` and `assets/`.
4. Open `Menagerie.pdf`: 47 pages. The bookmarks list `Menagerie`, `Beasts`
   and its entries (`Fen Hare` p. 2, `Marsh Owl` p. 4, `Cave Wyrm` p. 6,
   `Reed Cat` p. 8), `Horrors` p. 17, `Spirits`, `Quick Reference` p. 38,
   `Encounter Sheet` p. 39, `Relics` p. 41.
5. Page 1 (a right page): the chapter heading `Menagerie`, its intro and the
   section `Beasts`. Page 2 (left): `Fen Hare` with the statblock beside the
   opening paragraph: the band `◆ Fen Hare ◆`, 11 boxes in one row (groups
   of five), four cells with icons (Fine, Hurt, Down, Gone), `Might 5 ·
   Wits 0 · Speed 6`, the attacks `Kick 2d6` and **Bite** `1d6`, the tag
   `Beast`. Page 3's header reads `Fen Hare (continued)` (the entry runs
   over, `ENTRY_OVERFLOW`).
6. Pages 6–7: `Cave Wyrm` as a spread, the wide picture in the lower half of
   the right page. Page 8: `Reed Cat` with the text in a narrow column and
   the tall picture on the outer (left) edge.
7. `Bog Wight` (`full-image`): its right page (p. 19) shows only the
   picture, with no running header and no page number. Page 20 (`Dune
   Lark`) has the section's header `Horrors`, not `Bog Wight (continued)`
   (the first run's finding, fixed in `0.12.0`).
8. Page 38: the quick reference table (Entry, Section, vigour, Might, Wits,
   Speed, Track, Page — the box key has no stat label in this preset, so its
   column shows the key) on one page. Every text stays inside its cell
   (the first run's finding: `Section`, `Horrors`, `Tussock` ran into the
   next cell; fixed in `0.12.0`). Page 39: the encounter sheet page
   (see M23). Page 40:
   the encounter sheet page (see M23).
9. Print pages 6 and 7 (one spread) on A5 at 100 % (no "fit to page"). The
   statblock's boxes are square and about 3 mm; the icons are recognisable;
   no text overlaps the picture or the statblock (SCAR-025).
10. Open `export-warnings.md`: among others `ENTRY_AUTO "Ash Moth":
    page-portrait`, `SECTION_INTRO_OVERFLOW "Spirits"`, `ENTRY_YAML_INVALID
    "Lamp Wisp"`, `ENTRY_OUTSIDE_CHAPTER "Marsh Owl"`, three `IMAGE_LOW_DPI`.
11. Is anything missing, odd or ugly that this list did not ask about? Report
    it even if it seems unrelated (SCAR-015).
