# M19 — The settings screen of feature rows, and marked menu items (US-029 AC-1 to AC-12, AC-14)

Part of the [manual checks](../manual-checks.md).

**When:** after #111 to #114 (layout data and built-ins, sections and
modals, the preset screen, the menu prefix), and after any change to the
settings tab, the style panel's rows or the plugin's menu items.

**Needs:** Obsidian desktop. Prepared by the developer (SCAR-012): the test
build is installed in the scratch vault (`npm run install:scratch`; `main.js`,
`manifest.json`, `styles.css` byte-identical to the fresh build, `main.js`
sha256 `9d68f4fe266e…`), with the sample vault as `Sample/` (73 files). A new
preset note `Obsidian2Typst/presets/Settings check.md` (group `Print`) sets
`page.trimSize: A5`, `page.bleed: 3` and `page.folios: false`. The note
`Menus.md` (from M12) and the image `Layouting/Cover/wide.png` are used as they
are. Each of these names exists once in the vault, and `Settings check copy`
and `Settings scratch` do not exist (listing, 2026-10-31). The plugin data
(`data.json`: active preset `Book parts`, strict mode off; the Defaults set
`externalLinkFootnotes`, `linkPageNumbers`, `page.folios`,
`page.runningHeader` to `true`, `page.runningHeaderLevel` to 4 and three font
fields; they leave `page.facingPages` and every page geometry field unset),
every preset note and `Menus.md` are backed up in
`spikes/typst-wasm/m19-state-backup/before/` (24 files) and, as handed over,
in `handover/`, with checksums.

**Run in the scratch vault** (`spikes/typst-wasm/scratch-vault`). **Expected
version:** `0.14.0-m27.1` (first line of the settings tab, also the plugin
list). If it differs, stop: the wrong build is installed. Restart Obsidian once
so the new build is loaded.

**Known limitations:** the width of the space a row keeps where it has no
gear (AC-2) and the chevrons of the sections are CSS, judged here by eye.
Whether Enter and Space on a section heading open it inside Obsidian's
settings screen was not measured before this check (story, decision at G2):
step 2 is that measurement.

The titles, notes and table values below were measured from the files as
installed (the presets folder, `data.json`, `Menus.md`) through the plugin's
own functions (`lineContext`, the menu builders with `menuItemTitle`,
`ownedRowsNote`, `detailRows`; 2026-10-31, scratch probe `m19/m19.test.ts`).

## Steps

Keep the settings tab open from step 1 to step 8 (SCAR-016); close it only
where a step says so.

1. Open Settings → Obsidian2Typst. The first line reads `Obsidian2Typst
   0.14.0-m27.1`. Below it are five headings with a chevron: `Presets`
   (open), `Page`, `Text`, `Book`, `Export` (closed). Look at the tab at
   reading size: nothing overlaps, each heading is one line with its chevron
   (SCAR-025).
2. **Keyboard only:** press Tab until `Page` has the focus and press Enter:
   `Page` opens. Press Space: it closes. Press Enter again to leave it open.
   Does Enter or Space work on the heading? (This is the measurement of the
   story's open point; report what happens.)
3. In `Page` the rows are, in order: `Page setup` (a gear), `Page numbers`
   (a switch, on, and a reset icon), `Running header` (a switch, on, a reset
   icon and a gear), `Page breaks` (a gear). The switches of `Page numbers`
   and `Running header` stand one under the other (the row without a gear
   keeps its space). Open `Text` and `Book` and check their rows: `Text` —
   `Fonts` (gear), `Heading numbering` (a text field), `Highlight colour` (a
   text field), `Page numbers in links` (switch, reset, gear), `Footnotes for
   external links` (switch on, reset), `Template file` (a text field); `Book`
   — `Book parts` (gear), `Roman folios in the front matter` (switch off,
   reset), `Signatures` (gear), `Contents` (gear), `Image fit` (gear).
4. **The switch shows the value in effect (the G0 defect):** click the reset
   icon of `Footnotes for external links` and confirm `Reset`. The switch
   still shows **on** (the built-in value; before this build it showed off).
5. Click the gear of `Page setup`. A window titled `Page setup` holds, in
   order: `Trim size` (`A5`), `Trim width (mm)`, `Trim height (mm)` (both
   disabled, `Used only with a custom trim size`), the four margins, `Bleed
   (mm)`, `Slug (mm)`, `Facing pages` (a switch, **on**, although the
   Defaults do not set it), `Gutter (mm)`. Then:
   - switch `Facing pages` off: `Gutter (mm)` in the same window turns
     disabled with `Used only with facing pages`; switch it on again;
   - type `4` into `Bleed (mm)` and press Enter: the window stays open;
   - type `abc` into `Slug (mm)` and press Escape: the window closes and a
     notice reads `page.slug must be a number of at least 0`;
   - the `Page` section is still open and the tab did not jump to the top.
   Open `Page setup` again: `Bleed (mm)` shows `4`, `Slug (mm)` is empty.
   Click the reset icon of `Bleed (mm)` and confirm. Close the window with its
   close button.
6. Click the gear of `Text → Fonts`: the window lists `Font folder`, `Default
   font`, `Body font`, `Body size (pt)` (`12`), `Heading font`, `Heading size
   (pt)` (`18`), `Caption font`, `Caption size (pt)`, `Code font` (`DejaVu
   Sans Mono`), `Code size (pt)`. Close it with a click outside the window.
7. In `Presets`, each row has `Use` (`In use` for `Book parts`) and a gear;
   there are no `Details`, `Duplicate`, `Rename`, `Delete` buttons; `New
   preset` is below the list. Click the gear of `Settings check`: a window
   titled `Preset "Settings check"`; its table starts `Trim size | A5 | A5
   (preset)`, `Trim width (mm) | | — (preset)`, … `Bleed (mm) | 3 | 3
   (preset)`, `Slug (mm) | | 0 (built-in)`, `Facing pages | | true
   (built-in)`, … `Page numbers | false | false (preset)`, `Running header |
   | true (Defaults)`; further down `Pages per signature | | 0 (built-in)`,
   `Contents page numbers | | true (built-in)`, `Smallest image size | | 100
   (built-in)` (they read `—` before this build). The buttons are `Use`,
   `Open the note`, `Duplicate`, `Rename`, `Delete`, `Close`; `Close` has the
   focus (press Enter: the window closes). Open it again, then:
   - `Duplicate`: the list behind gains `Settings check copy`; the window
     still shows `Settings check`. Close it;
   - open the gear of `Settings check copy`, click `Rename`, type `Settings
     scratch` and press Enter: the window's title reads `Preset "Settings
     scratch"`;
   - click `Delete`: the question `Delete preset "Settings scratch"?` has the
     focus on `Cancel`; press Enter: nothing is deleted, the window stays.
     Click `Delete` again and then `Delete`: the window closes and `Settings
     scratch` is gone from the list.
8. Open `Export`: `Strict mode` (a switch, off, no reset icon, no gear),
   `Presets folder`, `Warnings note folder`. Close the settings.
9. In the ribbon menu (printer icon) the first items read `Export current
   note` and `Open style panel` (no prefix). Choose the preset `Settings
   check` (under `Print`). Open `Sample/Book.md` and the style panel. Below
   the preset dropdown are four closed headings: `Page`, `Text`, `Book`,
   `Cover`. Open `Page`: `Page setup` reads `Trim size, margins, bleed and
   facing pages. Set by preset "Settings check": Trim size, Trim width (mm),
   Trim height (mm), Bleed (mm).`; `Page numbers` shows its switch **off**,
   greyed, with `Set by preset "Settings check"; change it in the preset
   note`, and no reset icon. Click the gear of `Page setup`: `Bleed (mm)`
   shows `3`, greyed, with the same text, without a reset icon. Close it.
   In the ribbon menu choose `Book parts`: the panel redraws and `Page` stays
   open. Click the panel's `info` icon: the window `Preset "Book parts"` with
   the six buttons. Close it, and choose `Settings check` again.
10. Open `Menus.md`. Click into each line, then right-click inside the
    editor. Among Obsidian's own items the plugin's start with `O2T: `:
    - every line: `O2T: Export to PDF`, `O2T: Preview`;
    - line 1 `# Glossar`: `O2T: Use as glossary section`, `O2T: Table of
      contents before this heading`, `O2T: Table of contents after this
      heading`;
    - line 8 `# Glossary`: `O2T: Stop using as glossary section` and the two
      contents items;
    - line 16 `![[wide.png]]`: `O2T: Use as cover`;
    - line 18 (two images): `O2T: Use "quill.png" as cover`, `O2T: Use
      "m12-broken.png" as cover`.
    Click none of the preset items (or answer `Cancel` to the question). In
    the file explorer right-click `Menus.md`: `O2T: Export to PDF`, `O2T:
    Preview`; right-click `Layouting/Cover/wide.png`: `O2T: Use as cover`.
11. Is anything missing, odd or ugly that this list did not ask about? Report
    it even if it seems unrelated (SCAR-015).

After the check, the developer compares the preset notes, `data.json` and
`Menus.md` with `m19-state-backup/handover/` (checksums, Obsidian closed) and
restores what differs; `Settings check` stays unless the user asks to remove
it.
