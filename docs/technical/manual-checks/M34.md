# M34 — Prefilled encounter rows, end to end in Obsidian: compile, export, print (US-043)

Part of the [manual checks](../manual-checks.md).

**When:** after #184 and #185, before the release 0.17.0; ticket #186. Run together with the Vault Compiler's
check M24 (its ticket #136): one run, two records. What the tests cannot show is checked here (SCAR-024,
SCAR-045, SCAR-048): the callout in Obsidian, the compile through the installed Vault Compiler, the export through
the installed plugin with the vault's icons, and the printed page written on with a pencil.

**Needs:** Obsidian desktop and a printer. Prepared by the developer (SCAR-012, SCAR-018) in the scratch vault
(`spikes/typst-wasm/scratch-vault`, opened with `Open folder as vault`: the vault list still shows its old place):

- the **test build `0.17.0-m34.1`** of this plugin and the **test build `0.26.0-m24.1`** of the Vault Compiler,
  both installed and enabled;
- an invented adventure in `Encounters/`: three creatures (`Creatures/`), three rooms (`Rooms/`), the compile note
  `Bog Encounters.md`; the Vault Compiler set to compile it (`Entry marker keys`: `vigour`) into `Encounters/Out/bog-encounters.md`;
- the preset **`A4 Encounter Sheets`** (A4, margins 12/10/12/12 mm, a page break before H1 and H2, the statblock
  fields of the `Entries` preset);
- an empty export folder outside the vault: `~/Documents/Gits/Obsidian2Typst/spikes/m34/export`;
- the starting state: `spikes/m34/m34-before.txt` (315 files) and a full copy in `spikes/m34/vault-before/`, made
  while the scratch vault was not open.

**Run in the scratch vault**. **Expected version:** `0.18.0` (first line of this plugin's settings tab). If it
differs, stop.

**Decided before the run (SCAR-032):** each step names what is expected; the check passes when every step shows
it. A difference is written down with its step number and nothing is changed during the run; afterwards each one
is a bug (fixed and re-checked before the release) or a point the owner decides. A step that cannot be done is
recorded as not run. The numbers below were rehearsed in Node with both cores (`spikes/m34/rehearsal/`).

## Steps

1. Settings → Community plugins: **Obsidian2Typst 0.17.0-m34.1** and **Obsidian Vault Compiler 0.26.0-m24.1**,
   both on. Settings → Vault Compiler → section **Entry data**: the last row is **`Encounter callout type`** with
   `encounter`, description `Callout type of an encounter list (empty: off)`. Close the settings.
2. Open `Encounters/Rooms/1 Mire Hollow.md`: a callout titled *Night watch* with three lines; the creature names
   are links.
3. Command palette: **`Vault Compiler: Compile vault`**. Expected: the notice `✅ Compiled …` and the note
   `Encounters/Out/bog-encounters.md`, which shows three code blocks `o2t-encounter` (one per room) and, under *Old
   Weir*, the ordinary callout *Not an encounter* still as a callout. The warnings file of the compile lists three
   rows: `Encounter list: 2 lines not read (lines 6, 7)` and `Encounter list: no note "Fen Hair"` (both `2 Reed
   Bank.md`), and `link target 'Fen Hare' not embedded in compiled output` (`3 Old Weir.md`, the ordinary callout).
4. With `bog-encounters.md` open: ribbon icon `Obsidian2Typst` → preset **`A4 Encounter Sheets`**, then
   **`Export…`** to the export folder above. Expected: `bog-encounters.pdf` with **3 pages**; the warnings note lists
   `ENCOUNTER_BOXES_CAPPED` (`"Reed Wisp": 46 → 45`) and `COMMENT_DROPPED`.
5. Open the PDF. Page 1: *Bog Encounters*, *Mire Hollow*, the title *Night watch*, then 7 rows two across: `Fen
   Hare 1`, `Fen Hare 2` (note *nibbling reeds* on the first; 11 boxes; Might 4, Wits 1, Speed 5; `Move 5`;
   `Kick 2d6`; four cells), `Bog Wight 1` to `4` (note *1d4 (up to 4)* on the first; 20 boxes; three cells; two
   attacks), `Lost Pilgrim` (blank: empty boxes for the stats, 30 boxes, five cells, three ATTACK/DICE lines).
   Page 2: *Reed Bank*: `Reed Wisp 1` to `3` (45 boxes, no cells, the place empty), `Fen Hair` (blank).
   Page 3: *Old Weir*: `Bog Wight`; below it the *Not an encounter* callout. The icons in the cells are this
   vault's track icons.
6. Open the preview panel on `bog-encounters.md`: the same three pages.
7. Print page 1 at **100 %** ("actual size"). With a pencil, tick 5 boxes of `Fen Hare 1`, mark a cell of `Bog
   Wight 2`, and write a word on a NOTES line. Expected: every box, cell and line takes the pencil mark cleanly;
   nothing printed sits inside them; the text is readable at arm's length.
8. Anything missing, odd or ugly that this list did not ask about? Report it even if it seems unrelated.

## Record

Date, both builds, passed or the differences by step. The developer then compares the disk with what the steps
wrote (the compiled note, the warnings files, the PDF and `.typ`, the plugins' `data.json`) and undoes the vault
from the full copy (`shasum -c m34-before.txt`).
