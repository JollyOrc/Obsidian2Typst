# Obsidian2Typst v0.18.0

**Release date:** 2026-11-26
**Minimum Obsidian version:** 1.5.0 (desktop only)
**Tests:** 3644 tests passed, 1 `todo` (full run of the working tree, 2026-11-26; the clean-clone gate of the release build is recorded in the project's state files)

A statblock's name can now stand on a filled band.

---

## New features

- **A filled name band** with two optional keys of `entries.statblock`: `bandFill` (a colour or `none`) puts the
  band on that colour, reaching the frame on the left, top and right, with 1.6 mm below the name and no rule under
  it; `bandColor` is the colour of the name and its ◆ marks on it (without it, the frame colour). A name that wraps
  sits in one band. In `colorMode: grayscale` a filled band is `#4d4d4d` with white text. The same in the PDF, the
  preview, and everything drawn through the statblock API (for example Game Card Creator's creature cards). Example:
  `bandFill: "#8A4A2A"`, `bandColor: "#F3EEE3"`.

## Changed behaviour

- None without `bandFill`: the statblock, the PDF and the preview are byte-identical to 0.17.0 for the same input.
- With `bandFill` a statblock is 0.4 mm taller (the band's room below the name, less the rule it no longer needs);
  text beside it wraps around the new height. On a Game Card Creator card the band-only title is 1.6 mm taller.

## Breaking changes and migration

- None. The statblock API (`api.version` 1) keeps its shape; its prelude text changed in the band's drawing.
