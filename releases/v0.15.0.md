# Obsidian2Typst v0.15.0

**Release date:** 2026-11-12
**Minimum Obsidian version:** 1.5.0 (desktop only)
**Tests:** 2606/2606 unit, plugin and tooling tests passing (1 `todo` marker, as before); 676/676 integration tests passing (gate of 2026-11-12)

A feature release for other plugins: the plugin hands its statblock, as the
book draws it, to another plugin as Typst.

---

## What changes

- **`api.statblockTypst(data, options)`** (US-039): for one note's properties
  the answer is `{ok: true, prelude, data, files, credit, warnings}`: the two
  Typst definitions, the statblock's data exactly as the PDF export writes
  it, the icon files it names (`o2t-icons/<n>.svg`), the preset's credit and
  the data checks. Without a statblock setup or without a stat and an attack
  it answers `{ok: false, reason, message}`. The preset is read at every call.
- **`api.compileFonts()`**: the bundled fonts, then the vault fonts of the
  active preset, as the export hands them to the compiler.
- New warning `STATBLOCK_ICON_MISSING` (only in that answer).
- `api.version` stays 1; `renderStatblock`, `renderDetails` and the export are
  unchanged.
