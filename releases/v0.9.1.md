# Obsidian2Typst v0.9.1

**Release date:** 2026-10-27
**Minimum Obsidian version:** 1.5.0 (desktop only)
**Tests:** 1826/1826 unit, plugin and tooling tests passing (1 `todo` marker,
as in 0.9.0); 389/389 integration tests passing (1 skipped without the Typst
CLI)

The first release from the GitHub repository, with the tag `0.9.1` (the
manifest version, as Obsidian expects). The plugin's code is unchanged:
`main.js` is byte-identical to 0.9.0.

---

## New: a public test vault (US-024)

The tests and the manual checks no longer need the author's private vault.

- A generator (`npm run fixtures`, `tests/fixtures/generate.ts`) writes a
  sample vault into `tests/fixtures/sample/` from a fixed seed: a long filler
  note `Book.md` (7234 lines, 669 headings, 273 tables, callouts of every
  built-in type, a glossary of 42 terms, 70 images), a short `Other.md`, a
  preset note and a manifest that counts what was written. The vault is
  committed; a test checks that it equals a fresh run.
- Every test that read the private vault now reads the sample vault and takes
  its expected numbers from the manifest. The sample covers at least every
  count and every combination of elements the private note had.
- `npm run install:scratch` also installs the sample vault into the scratch
  vault as `Sample/`; the manual checks M1 to M13 name its notes and state
  values measured from it.
- Tests keep the private vault, personal data and quoted text out of the
  published files, and a copy of only the published files passes the whole
  quality gate.

## New: licence and notices

- The project is under the MIT licence (`LICENSE`, copyright JollyOrc).
- `THIRD_PARTY_NOTICES.md` lists every component that `main.js` bundles
  (markdown-it and its parts, yaml, typst.ts with its compiler and renderer,
  the Libertinus Serif and DejaVu Sans Mono fonts) with its licence text. It
  names one limit: the licence texts of the Rust code compiled into the two
  WebAssembly binaries are not shipped with typst.ts and are not reproduced.
