# Obsidian2Typst v0.19.0

**Release date:** 2026-11-26
**Minimum Obsidian version:** 1.5.0 (desktop only)
**Tests:** 3683 tests passed, 1 `todo` (full run of the working tree, 2026-11-26; the clean-clone gate of the release build is recorded in the project's state files)

A note can name its own preset.

---

## New features

- **A preset for one note:** the property `typst-preset` in a note's frontmatter chooses the preset that note is
  exported and previewed with; the active preset stays as it is. The export dialog starts on the note's preset
  (another choice there exports with it once); the style panel shows the note's preset and locks its list. The name
  is compared as the preset list compares names. An unknown or invalid name is refused with a message naming the
  property: `Preset "X" (from this note's properties) does not exist.`
- **O2T: Preset for this note…** in the note menus: a chooser (Active preset first, then the presets, the current
  one marked) that writes or removes only `typst-preset`; the note's other properties keep their bytes.
- The Obsidian Vault Compiler 0.27.0 copies `typst-preset` from its starting note into the compiled note.

## Changed behaviour

- None for notes without `typst-preset`: export, dialog and preview as in 0.18.0. The reading-view statblocks and the
  API keep using the active preset.

## Breaking changes and migration

- None.
