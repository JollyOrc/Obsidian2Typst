## What the plugin does

Obsidian2Typst converts one Markdown note, and the images it links, into a
Typst document. It then compiles the document to a print-ready PDF inside
Obsidian, with a bundled Typst compiler; no `typst` installation is needed.
Print layout is set in presets: notes in a presets folder of the vault.

### Conversion (Markdown to Typst)

- Text, inline formatting, lists, quotes and code blocks (US-001).
- Headings with automatic numbering and labels (US-002).
- Images and embeds: the files are copied with the output, sized as written
  or fitted to the page (US-003).
- Links, wikilinks and anchors as PDF links. External links can also be
  printed as footnotes (US-004).
- Tables, footnotes and task lists (US-005).
- Conversion warnings with source line numbers, in an export warnings note.
  An optional strict mode stops on warnings (US-006).
- One escaping module keeps every generated Typst file valid (US-013).
- Obsidian Markdown (wikilinks, embeds, callouts, frontmatter) is parsed with
  one specified parser (US-014).
- One conversion pipeline with a fixed order of preamble rules and a line
  map back to the note (US-015).
- Callouts become styled boxes, with built-in and user-defined styles and
  icons (US-016).
- Heading rules: a `Glossary` heading (or any heading a preset maps to
  `glossary`) turns its sub-headings into glossary term entries (US-017).
- Page numbers after internal links, at a chosen heading depth and with a
  chosen word (`S.`, `p.`) (US-018).
- Page numbers (folios) and a running header with the chapter title
  (US-019).

### Print settings

- Presets stored as vault notes, Defaults in the plugin settings, and an
  optional Typst template file (US-008).
- Page setup: trim size, margins, gutter, bleed, slug and facing pages
  (US-009).
- Fonts: a default font, overrides per role, and a font folder in the vault
  (US-010).
- A cover image: automatic (the first image of the note), a chosen file, or
  none, with a warning when the image would be cropped (US-011).

### In Obsidian

- Compile to PDF inside Obsidian with the bundled WASM compiler, in a
  worker, one export at a time (US-007).
- A style panel in the right sidebar: a live preview of the PDF, driven by
  the active preset (US-012).
- One function per action, a ribbon menu, and menu items in the file
  explorer and the editor (`Export to PDF`, `Preview`) (US-020).
- Preset groups (`group:` in a preset note) in the panel, the settings tab
  and the ribbon menu, and a details pop-up showing each setting's value and
  where it comes from (US-021).
- Heading and image menu items that change the active preset: `Use as
  glossary section`, `Use as cover` and their `Stop using …` items. The
  plugin asks first, then changes only that one key of the preset note
  (US-022).

### Presets that ship

When the presets folder does not exist yet, the plugin creates it with two
presets. An existing folder is never changed.

| | A5 print | A4 digital |
|---|---|---|
| Trim size | A5 | A4 |
| Margins top / bottom / inside / outside (mm) | 18 / 22 / 15 / 15 | 20 / 20 / 20 / 20 |
| Gutter / bleed / slug (mm) | 5 / 3 / 0 | 0 / 0 / 0 |
| Facing pages | yes | no |
| Page numbers after links | on (the default) | off |

## Known limitations

- Desktop only (`isDesktopOnly`).
- Remote images (`https://…`) are not downloaded; a placeholder and a
  warning take their place.
- PDF/A and PDF/UA are not selectable through typst.ts 0.7.0. PDF/X is not
  available. CMYK fills are kept in the PDF, without an OutputIntent.
- The heading and image menu items act on the line of the cursor: a
  right-click does not move the cursor (measured in M12, Obsidian 1.14.4).
  Click into the line first. A backlog item covers the clicked line.
- The Typst compile has no warnings channel: an unknown font family or a
  missing glyph is not reported by the compiler (the plugin checks glyphs
  itself).
