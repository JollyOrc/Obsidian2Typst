# Obsidian2Typst v0.11.0

**Release date:** 2026-10-31
**Minimum Obsidian version:** 1.5.0 (desktop only)
**Tests:** 2119/2119 unit, plugin and tooling tests passing (1 `todo`
marker, as before); 480/480 integration tests passing (1 skipped without the
Typst CLI)

A new settings screen: the settings are grouped by what they do, with a
switch where a feature can be turned on or off and a window for its detail
settings. The plugin's menu items are marked as the plugin's. Exports are
unchanged.

---

## New: a settings screen of feature rows (US-029)

- The settings tab has five collapsible sections: **Presets**, **Page**,
  **Text**, **Book**, **Export**. Presets is open when the tab first opens; a
  section stays open or closed until Obsidian closes.
- A **feature row** names a feature: a switch where it can be turned on or
  off (Page numbers, Running header, Page numbers in links, Footnotes for
  external links, Roman folios, Strict mode) and a gear (⚙) that opens a
  window with its settings (Page setup, Running header, Page breaks, Fonts,
  Page numbers in links, Book parts, Signatures, Contents, Image fit).
  Single settings stay plain rows (Heading numbering, Highlight colour,
  Template file, the two folders).
- The style panel uses the same sections (Page, Text, Book, plus Cover),
  closed at first. A feature row names the settings behind its gear that the
  active preset sets, for example `Set by preset "A5 print": Trim size, Trim
  width (mm), Trim height (mm), Bleed (mm).`
- In a settings window every field saves as on the tab. Closing the window
  (Escape, the close button, a click outside) saves what was typed but not
  yet saved; a value that is not allowed then shows its message as a notice.

## New: the preset's window (US-029)

- A preset row has **Use** and a gear. The gear, and the info icon of the
  style panel, open the preset's window: the table of every setting with its
  source, and **Use**, **Open the note**, **Duplicate**, **Rename**,
  **Delete**, **Close** (Close has the focus; Delete still asks first). After
  a rename the window shows the new name; an active preset stays active.

## New: menu items marked `O2T:` (US-029)

- Every item the plugin adds to the file explorer and editor menus starts
  with `O2T: `, for example `O2T: Export to PDF`, `O2T: Use as cover`. The
  ribbon menu (the plugin's own) and the commands are unchanged.

## Fixed

- A switch of the Defaults showed **off** while the Defaults did not set it,
  although an export used the built-in value **on** (Facing pages, Page
  numbers, Running header, Page numbers in links, Footnotes for external
  links, Contents page numbers, Contents dot leaders). Switches now show the
  value an export uses.
- The preset table showed `—` for the built-in value of 16 settings (Break
  before H1 to H6, Pages per signature, Roman folios, First chapter,
  Colophon heading, Back notes heading, the four Contents settings, Smallest
  image size). It now shows the built-in value, e.g. `true (built-in)`.

## Changed behaviour

- Rows moved: most Defaults rows are now behind a feature row's gear (see
  the [user manual](../manual/manual.md#the-settings-tab)). The preset
  table lists the settings in the order of the sections.
- The `Details`, `Duplicate`, `Rename` and `Delete` buttons left the preset
  rows; they are in the preset's window.
- Known limitation: in the settings tab, Tab does not reach a section
  heading (the focus goes to the first item inside), so a section is opened
  with the mouse.

## Breaking changes and migration

None. `data.json` and preset notes keep their format; exports are
byte-identical.
