# Obsidian2Typst v0.14.0

**Release date:** (draft; not released)
**Minimum Obsidian version:** 1.5.0 (desktop only)
**Tests:** 2555/2555 unit, plugin and tooling tests passing (1 `todo`
marker, as before); 659/659 integration tests passing (gate of 2026-11-09)

Detail rows (epic #152, US-038): a few properties of a note drawn as one
row of icon-and-label badges directly under its heading, in the PDF and in
Obsidian, from a new generic `o2t-details` block and a new preset group
`details`.

---

## What changes

- A fenced block with the info string `o2t-details` directly under a heading
  holds some of the note's properties as YAML. The format is the contract
  `docs/technical/details-block.md`; the Obsidian Vault Compiler will write
  the blocks.
- The preset note's new `details` group (`items`, `color`, `size`) says which
  badge each key becomes: an icon and a label per value, a flag's label only
  when it is true, an unlisted value printed as written. Without the group
  there is no row and no warning.
- The PDF row is one unjustified paragraph in the preset's colour and size
  (grayscale follows `colorMode`), icons 0.95 em, 1.1 em between badges; it
  wraps, keeps each icon with its first word, and stays with its heading and
  the text after it. It is not a heading: not in the contents or the outline.
- A link in a value stays a link, with a page number under the rules of the
  other links.
- Obsidian draws the same row for `o2t-details` blocks (reading view and
  live preview) and `api.renderDetails(el, data, options)` draws it for your
  own views; `api.version` stays 1.
- Eight new warnings, `DETAIL_YAML_INVALID`, `DETAIL_ORPHAN_BLOCK`,
  `DETAIL_BLOCK_TWICE`, `DETAIL_BLOCK_IN_CONTAINER`, `DETAIL_IN_GLOSSARY`,
  `DETAIL_BLOCK_WITH_ENTRY`, `DETAIL_VALUE_NOT_TEXT` and
  `DETAIL_VALUE_UNMAPPED`; strict mode stops on them like on every conversion
  warning.

## Breaking changes and migration

None. A note without `o2t-details` blocks, or a preset without the `details`
group, converts as before. Before this release an `o2t-details` block was
printed as a code block: update the plugin before the blocks are written.

## Known limits

- The icons' licence texts are not printed by the plugin; put the credit of
  the icons you use into your book's own credits.
- The row's width rules were measured in WebKit; Obsidian's own engine and
  the published site were not measured by the tests. Manual check M27.
